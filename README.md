# Proximity Gesture Detection Machine Learning Acquisition Firmware
This firmware is used in the proximity gesture detection project to build the training dataset. This project uses an [M.2 breakout board](https://store.particle.io/collections/all-products/products/particle-m-2-som-breakout-board) with the [B504e](https://store.particle.io/collections/all-products/products/b-series-lte-cat-1-3g-noram-ethersim-x1) as the main, LTE CAT 1 enabled processor. The sensing element is a [VCNL4040](https://www.adafruit.com/product/4161) proximity breakout. The user interface is a [OLED Featherwing from Adafruit](https://learn.adafruit.com/adafruit-128x64-oled-featherwing).
